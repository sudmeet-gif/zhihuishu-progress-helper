# 智慧树资源进度助手

一个供 Edge 和 Chrome 使用的本地浏览器扩展。它在用户本人登录智慧树后，按页面显示的资源列表打开未完成的课件，并以 **1× 原速**播放视频。扩展以官网显示的“已完成”为准，不修改平台进度接口。

**作者：Zhang Jinrui**

当前版本：0.3.1

## 功能

- 在已识别的智慧树 AI 课程资源列表中，按顺序处理未完成的 Word、PPT 和视频。课件点开后等待官网显示“已完成”；视频播放到结束后再核对完成标识。
- 当前知识点的资源均完成后，尝试查找同一课程中下一个显示“必学 x/y”且未完成的知识点。
- 遇到弹题、测验或验证码时暂停播放，等待用户本人处理。扩展不答题、不提交答案。
- 在其他受支持的课程页面上，若能识别标准 HTML 视频，也会尝试播放；只有唯一且明确的“下一节”按钮时才尝试继续。

## 安装

1. 下载本仓库源码并解压。Edge 打开 `edge://extensions/`，Chrome 打开 `chrome://extensions/`。
2. 开启“开发人员模式”，选择“加载解压缩的扩展”，选中含 `manifest.json` 的仓库根目录。
3. 点击扩展图标打开智慧树官网，**由用户本人在官网完成登录**，再进入要学习的课程资源页。
4. 在页面右下角的“智慧树资源进度助手”面板点击“启动”。“完成后检查下一知识点”默认开启，可随时关闭；“暂停”会停止助手处理当前视频。

扩展不绑定任何课程编号，也不需要填写账号或密码。切换到其他课程后，在该课程的学习页继续使用即可。

## 完成判定与限制

- Word/PPT 被打开后，只有官网显示“已完成”才会继续处理下一个资源。
- 视频保持 1×。若浏览器拦截自动播放，会尝试静音播放；仍被拦截时，需要用户手动点击一次播放。视频播完后若官网尚未标记完成，会原速重播一次，之后仍未完成则暂停提示。
- 下一知识点的自动切换只在页面目录可识别时工作；找不到入口会停下，不会自动进入另一门课程。
- 不同课程可能使用不同页面结构。真实课程页已验证 PPT 点开后的完成标识；视频顺序、速度、弹题等待和知识点切换通过模拟页面测试，真实视频播放尚未完成在线验证。
- 学习进度由智慧树平台计算；本扩展无法保证所有课程都能自动完成。

## 隐私

本仓库不包含账号、密码、验证码、Cookie、登录会话、课程专属链接或调试浏览器资料。扩展代码不读取这些数据；它仅在本机保存“启动”和“继续下一知识点”等设置，资源标题与运行状态不会持久保存。请只在自己的浏览器中安装，登录、验证和弹题操作由本人完成。
